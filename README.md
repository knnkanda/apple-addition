# 🍎 りんごのたしざん

神田レオン　現在6歳　の子どもが、りんごを動かしながら「足し算とは、数が増えること」を体験できるブラウザゲームです。

## このゲームを作った理由

子どもが「＋2」の計算に取り組んでいるとき、数直線を見ながらなら答えを出せても、式だけになると答えが1ずつずれてしまうことがありました。

たとえば「4＋2」を、4から数え始めて「4、5」と数えてしまい、5と答えてしまいます。答えを覚える以前に、「最初の4個とは別に、あとから2個が増える」という足し算の概念が、まだ十分に目で捉えられていなかったのです。

そこで、紙の問題を繰り返すだけではなく、りんごを1個ずつ増やし、増えた様子を見てから全部を数えられるゲームを作りました。正解の速さよりも、子ども自身が「なぜこの答えになるのか」を理解することを目指しています。

## 遊び方

1. 難しさを選びます。
2. 「1こ ふやす」を押して、りんごを問題の数だけ増やします。
3. 最初のりんごと増えたりんごを数えます。
4. 1〜10から答えを選び、「こたえあわせ」を押します。
5. 10問終えると結果が表示されます。

## 3つのモード

| モード | 出題内容 | 目的 |
| --- | --- | --- |
| かんたん | ＋1・＋2 | 数が1個、2個増える感覚をつかむ |
| ふつう | ＋1〜4 | 複数個を加える練習 |
| ちょうせん | 答えが10までの足し算 | 絵を隠した状態から考える |

答えはすべて10以下です。「ちょうせん」でも、分からないときはりんごを表示して考え直せます。

## 学習設計

- 数字だけでなく、りんごの個数で量を表します。
- 追加するりんごを1個ずつ表示し、「増える過程」を見せます。
- 間違えても正解をすぐに教えず、もう一度数えられるようにします。
- 10問を一区切りにし、達成感を得られる構成にしています。
- 計算速度や暗記より、足し算の意味を説明できることを重視します。

## 動かし方

外部ライブラリやサーバーは不要です。

1. \`index.html\` をダウンロードします。
2. Safari、Chromeなどのブラウザで開きます。

スマートフォン、タブレット、パソコンのブラウザで利用できます。
